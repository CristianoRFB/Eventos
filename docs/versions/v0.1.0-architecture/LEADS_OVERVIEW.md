# Visão de leads — fase de projeto

Base relatada de pesquisa: `LEADS_MASTER_77` no Drive, seis eventos priorizados em auditoria anterior (qualificação a conferir). Este pacote não baixa dados sensíveis nem publica material comercial de terceiros. A implementação futura deve possuir um fluxo de prévia 100% fictícia e só transformar um lead em tenant real após consentimento/contrato.

Protocolo: pesquisa -> briefing e fontes -> proposta visual rotulada -> contato humano aprovado -> autorização -> onboarding -> domínio verificado -> publicar. Não criar leads falsos nem transformar organizadores famosos em casos oficiais.
