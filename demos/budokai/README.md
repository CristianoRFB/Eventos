# Budokai Matsuri — demonstração não oficial
Prévia independente para lead Budokai Geek Store Natal/RN, sem aprovação/contratação declarada.

## Abrir
O arquivo demos/budokai/index.html é estático e autossuficiente: abra no navegador ou use servidor estático. Não faz chamadas à API, não envia dados nem cobra ingressos.
- #inicio: portal do evento, convidados, local e links oficiais.
- #programacao: grade ilustrativa, escolha por dia, salvar/limpar atividades (estado da sessão).
- #gestao: editor de demonstração sem senha, que altera capa e grade local, jamais o evento real.
